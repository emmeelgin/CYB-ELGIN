Connect Supabase and set up teacher access
  1. Run supabase-setup.sql in your Supabase project's SQL Editor.
  2. If you ran an earlier version, run the updated script again. It adds the due-date column and student roster/progress functions.
  3. Create your teacher account in Supabase Authentication, then run the final SQL statement after replacing teacher@example.com with your account email.
  4. After signing in, add your students in the roster above. Enter one name per line as First name,Last name.
  5. The public project URL and publishable key are configured in this page. Never put your database password or a service-role/secret key in website code.
