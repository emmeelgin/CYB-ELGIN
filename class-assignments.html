First-time setup and backend connection
  1. Create a free project at Supabase.
  2. Open its SQL Editor, paste in supabase-setup.sql, and run it. The script creates the tables and access rules.
  3. In Supabase Authentication, create your teacher account. In the final statement of the SQL script, replace teacher@example.com with your account email and run that statement to grant teacher access.
  4. Open Project Settings → API and copy the Project URL and the public anon/publishable key (never use a service-role or secret key in this website).
  5. Enter those values below. To make the site ready for every student, put them in the SUPABASE_URL and SUPABASE_ANON_KEY constants in this file before publishing it. The public key is safe to expose because database access is restricted by the SQL policies.
